## Confirmed G0 issues and fixes

- **R1 — PPO ratio/clip no-op**: `trainer.py` previously recomputed `old_logp` with the live policy, so `ratio ≡ 1` and PPO clipping never bound. Fixed by caching sample-time `old_logp` in `rollout.py` (`rollout.py:107-116`, `179-183`) and consuming it in `trainer.py` (`trainer.py:189-196`) with ratio/clamp telemetry (`trainer.py:207-214`, `231-245`).
- **R2 — best-of-group trajectory advance**: `rollout.py` previously advanced with `argmax(reward)`, biasing later states. Fixed with selectable `advance_policy` and default `sampled` (`rollout.py:65-67`, `185-189`).
- **R3 — global stateful reward z-norm**: `rewards.py` previously used a process-global running Welford normalizer by default. Fixed with per-group component normalization default (`rewards.py:84-99`, `188-235`) and explicit reset/checkpoint APIs for the legacy running path (`rewards.py:36-67`, `101-114`).
- **README discrepancy**: `train/README.md:24` claimed a clipped surrogate while R1 made it inert pre-fix; the implementation now matches the claim.
- **R_phr blacklist gap**: default config now includes `first image`, `second image`, `third image`, `the first image`, and `the second image` (`grpo_default.yaml:87-91`).
- **Text similarity range**: `ClipEmbedder.cosine` maps raw cosine from `[-1,1]` to `[0,1]` (`text_sim.py:45-52`).
- **Metrics NIQE direction**: `score_all()` negates NIQE while preserving raw `score()` outputs (`metrics.py:55-70`).
- **State scale token**: expanded-state prompt now emits literal `zoom factor={scale}x` (`state.py:14-21`).

G0 VERDICT: PASS
